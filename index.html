RoboBuddy IDE
Physics Preview

Development branch for migrating RoboBuddy IDE from demonstration-oriented simulation toward a shared, physically meaningful MuJoCo architecture while preserving the IDE and WebMCP workflow.

Alpha architecture preview. This release is not yet the completed physical simulator. The physical backend contracts, versioned scene/command/observation schemas, capability registry, session lifecycle, and live async Python bridge are being established before robot migrations. No hardware-fidelity claim is made.
